# Small-Projects
During my internship at Quastech, Vashi, I developed different Python-based programs to improve my understanding of programming concepts and logical problem-solving. I created projects such as a Movie Ticket Booking System and an LNT Parking System, where I used variables, conditional statements, loops, user input, dictionaries, and basic calculations. While developing these programs, I learned how to design menu-driven applications, handle different user choices, calculate ticket and parking charges, keep track of available slots, and display appropriate messages when the parking area was full. These activities helped me gain practical experience in Python programming and improved my confidence in developing simple real-world applications.
